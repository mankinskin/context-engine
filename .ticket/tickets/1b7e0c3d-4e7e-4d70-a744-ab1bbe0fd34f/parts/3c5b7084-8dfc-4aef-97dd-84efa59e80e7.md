## Decisions

- **Decision 1: dependency resolution policy is git URLs.** All cross-repository dependencies resolve by git URL, following the existing precedent `transport-harness = { git = "https://github.com/mankinskin/memory-kernel", branch = "main" }`. Relative submodule paths are allowed only as an explicitly documented superproject development override, never as the committed default. For this ticket, all 23 former consumers of the legacy base crate resolve `memory_kernel` by git URL.
- **Decision 2: duplicated `InteroperableArtifact` contract is merged to one definition with rule-based placement.** If the contract is specific to the test/validation domain, it lives in `test-api`; if it is generally relevant to all memory tools (ticket, spec, session, audit, doc, log, feedback, test), it lives in `memory-kernel`, and `test-api` implements the kernel-owned trait for its own types. The placement outcome follows from this rule and is being determined by a separate analysis, so the rule itself is resolved even though the final home is pending that analysis.
