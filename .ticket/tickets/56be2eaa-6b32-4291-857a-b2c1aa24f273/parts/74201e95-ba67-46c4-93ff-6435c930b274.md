## Objective

Add a live/integration verification path for mcp-cost-gate so that expensive-model gating can be verified end-to-end. Today mcp-cost-gate is an MCP stdio proxy with no standalone verdict CLI, which is why AC7 of ticket 9185d8f2 was waived (manual smoke check: expensive-model MCP call to `get_ticket_description` succeeds instead of returning cost errors).

## Problem

Acceptance criterion AC7 from ticket 9185d8f2 ("Manual smoke check: an expensive-model MCP call to `get_ticket_description` succeeds") could not be executed in-session because mcp-cost-gate has no standalone verdict CLI or integration test harness. Expensive-model gating is currently verified only via unit/proxy tests, not end-to-end with real expensive-tier caller_model invoking actual MCP tools.

## Scope Hints

Choose one of:
1. Small `mcp-cost-gate` subcommand that prints the gate verdict for a given (caller_model, tool) pair, taking a cost rollup file and model price table as inputs.
2. Integration test harness that drives the stdio proxy with synthetic JSON-RPC frames, verifying that expensive models are gated and cheap models are allowed.

## Non-goals

- Modifying the cost gate logic itself (that's in 9185d8f2).
- Populating or repairing the tool-metrics rollup writer.
