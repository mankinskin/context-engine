## Minimal Consumer Install Proof

Registered `workflow-minimal-demo` (`https://github.com/mankinskin/workflow-minimal-demo`) as a top-level meta-workspace submodule. The workspace is the implementation repository for the minimal-demo consumer contract.

Added `workflow-tools/bootstrap.sh`, the single pinned ticket/spec CLI installation and initialization path. The bootstrap requires both `--root` and `--workspace`, installs only into `<root>/bin`, and initializes explicit `<workspace>/.ticket` and `<workspace>/.spec` index roots.

The initial tutorial exposed and corrected parent-store fallback: explicit workspace roots now resolve directly to their own hidden store in memory-kernel, and the bootstrap/tutorial pass `--index-root` so released CLIs cannot discover a superproject store.
