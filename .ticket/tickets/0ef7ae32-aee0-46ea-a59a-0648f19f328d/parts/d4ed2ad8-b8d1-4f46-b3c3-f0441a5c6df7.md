## Requirements

- Canonical directories are `.workflow-tools/ticket`, `spec`, `test`, `session`, `feedback`, `log`, `doc`, `rule`, and `audit`.
- The namespace behavior follows spec `02c6700d-6ab2-44a8-aa69-4052ad2f76bb`.
- A legacy `.<domain>` directory is readable only if its canonical counterpart is absent; the resolver reports a deprecation diagnostic.
- Writes, sidecars, indexes, and store initialization target only the canonical location.
- Coexisting populated legacy and canonical locations are rejected as ambiguous.
- Migration must preflight, apply atomically where possible, verify content/index visibility, and preserve source contents on failure.
