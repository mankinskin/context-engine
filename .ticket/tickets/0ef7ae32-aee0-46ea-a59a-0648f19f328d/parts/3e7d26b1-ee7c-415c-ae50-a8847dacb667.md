## Acceptance Criteria

1. Resolver tests cover canonical-only, legacy-only, both-present ambiguity, and absent-store creation behavior for every supported domain.
2. Domain transport tests prove writes and index sidecars land beneath `.workflow-tools/<domain>` and legacy reads emit the expected diagnostic.
3. Migration tests preflight/apply/read back a populated store, reject collisions, and preserve source data after a forced failure.
4. Context-engine production stores and all affected fixtures use the canonical layout; no production configuration references a flat `.<domain>` write target.
5. Focused test commands and read-back evidence are recorded on each child ticket before review.
