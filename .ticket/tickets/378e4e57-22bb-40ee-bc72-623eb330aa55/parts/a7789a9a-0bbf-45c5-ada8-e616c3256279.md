## Decision

Delete `.agents/agents/Default.agent.md` outright. Do not replace the template with a contract.

## Rationale

The Default agent template has lost its place. The specialist roster now covers the routing space, and a contract-free fallback target is worse than no target at all.

## Generated Mirror

The generated mirror directory `.github/agents/` is produced from `.agents/` by `bootstrap.sh` / `rule sync-targets`. The implementation must regenerate the mirror after deleting the canonical template rather than manually deleting files in both directories.
