## Objective

Extend the workflow-tools-owned `install-ctl` with a scriptable interactive configuration flow that selects the minimal tutorial bundle, an installation home, agent guidance, and hooks. Support a documented prebuilt-artifact source or cache so the Docker installation test installs delivered binaries rather than compiling selected workflow-tool binaries from source.

## Done Condition

- The configuration flow is driveable with `ratatui-testlib`.
- Selected binaries land under `<installation-home>/.workflow-tools/bin/`.
- The selected prebuilt source is verified and reused on a later run.

## Validation

Automate the TUI selection with ratatui-testlib, read back installed files, and run the selected installed transport with `--help`.
