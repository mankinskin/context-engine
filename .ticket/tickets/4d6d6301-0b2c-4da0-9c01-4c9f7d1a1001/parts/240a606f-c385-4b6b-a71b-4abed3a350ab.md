## Objective

Move `install-ctl` from `context-engine/tools/install/install-ctl` to `workflow-tools/tools/install/install-ctl` and move the canonical registry to `workflow-tools/tools/install/artifacts.toml`. The relocated binary must resolve the registry from the workflow-tools source root, interpret every source path relative to that root, preserve catalog generation, and avoid context-engine-specific source paths.

## Done Condition

- `install-ctl --list` resolves the workflow-tools registry.
- Registry entries cover workflow-tools source artifacts and use workflow-tools-relative paths.
- The generated catalog is current.
- Focused build and registry tests pass.

## Validation

Run `cargo test` for the relocated installer crate, invoke `install-ctl --list` from outside the source root, and run the catalog freshness check.
