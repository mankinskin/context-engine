## Objective

Add root `workflow-tools/install.sh` as the public, commit-pinned consumer bootstrap. The script installs `install-ctl` into the selected consumer workspace through Cargo; `install-ctl` then installs every selected tool, instruction, hook, and binary under `<installation-home>/.workflow-tools`.

## Done Condition

- One documented `curl | bash` command fetches `install.sh` at an explicit workflow-tools commit.
- The script uses the same commit for the Cargo source and does not install workflow tools globally.
- `install-ctl` owns subsequent selection and installation.

## Validation

Run the script in a fresh temporary consumer directory and verify the local install-ctl path plus selected installation-home contents.
