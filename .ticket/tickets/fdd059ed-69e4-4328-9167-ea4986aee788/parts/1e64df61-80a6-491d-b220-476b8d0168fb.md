Rework Terminal Command Agent as an autonomous general-purpose terminal executor. The agent must execute clear user-requested commands without permission prompts, use COMMANDS.md as the repository command-surface reference without restricting ordinary shell usage to catalog entries, support bounded multi-command batches and short scripts, and use runtime tool schemas as the source for client tool invocation. The agent must choose explicit working directories, preserve command order and failure handling, avoid secrets and privilege escalation, and report executed commands, outcomes, and blockers concisely.
