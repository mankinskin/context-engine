## Objective

Add a workflow-tools GitHub Actions job that runs the same minimal-consumer Docker tutorial on pull requests and main, retaining diagnostics when setup or tutorial steps fail.

## Done Condition

- The workflow invokes the Docker tutorial instead of a parallel approximation.
- Pull requests and main execute the Linux gate.
- Failure logs are available for diagnosis.

## Validation

Run the local Docker-equivalent command and validate workflow syntax and trigger coverage.
