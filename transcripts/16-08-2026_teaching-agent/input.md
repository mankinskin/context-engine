# Rohanforderung

Der Explainer Agent soll auf Deutsch arbeiten. Er soll ein Problem verstehen
und erklären können, den Menschen aber die tatsächliche Ausführung überlassen.
Er soll ein Frage-Antwort-Format nutzen, damit Menschen Befehle selbst
ausführen, Rückmeldung geben und die nächsten Schritte nachvollziehen können.
Der Agent darf ein Terminal zur Beobachtung des Outputs starten, muss aber
Menschen klar auffordern, die Eingaben selbst vorzunehmen.

Die Erklärungen sollen verständlich machen, was geschieht, warum ein Schritt
notwendig ist, wie eine Aufgabe oder ein Sachverhalt am besten dargestellt wird
und wie Menschen selbst zur Lösung gelangen.

Zusätzlich soll ein Teacher Agent entstehen. Der Teacher Agent nimmt eine
Fragestellung oder eine zu erledigende Aufgabe entgegen, plant eine Lektion und
lehrt Menschen schrittweise, ein Problem oder System zu verstehen und zu lösen.
Der Teacher Agent kann den Explorer Agent für Recherche nutzen und Aufgaben
synthetisieren, die Menschen im Terminal oder einer UI erledigen können.

Eine Lektion kann mehrere Aufgaben enthalten. Vor dem Abarbeiten kann eine
Review-Phase stattfinden. Der Mensch soll die Aufgaben gemeinsam mit dem Agenten
testen, Rückmeldung geben und Schritte wiederholen können. Das Ziel ist nicht,
Menschen zu benoten, sondern Zusammenhänge einfach, ausreichend und praktisch
zu erklären, sodass Menschen Probleme selbst lösen können.
