# Agent Harness with an Interactive Chat UI

## Goal

Extend the agent harness we already planned so that it includes a **chat UI** the agent can actively control. Through this UI the agent interacts with a virtual world — for example the UI scene, displayed images, colors, or the format of the chat message itself.

The deliverable is a **skill** that describes which interactions the agent can perform inside the shared UI "sandbox" — the common interface between the agent and the user.

## Interactions the Skill Should Cover

- Generate question-and-answer UI elements.
- Request different kinds of input from the user.
- Turn on the microphone.
- Output specific text.
- Other similar UI interactions as needed.

## Objective

Firmly anchor this goal in the agent harness's own objective, so that we can develop our own chat UI — for example, along the lines of OpenCode.
