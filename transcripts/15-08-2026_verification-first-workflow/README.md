# Verification-First Workflow Dossier

## Purpose

This dossier turns the transcript's verification-first thesis into a bounded,
research-backed one-session deliverable. It does not implement product changes.

## Reading Order

1. [Review](REVIEW.md) identifies the original plan's execution gaps and the
   required corrections.
2. [Research Inventory](01-research-inventory.md) records the repository
   capabilities that constrain the proposal.
3. [Verification Operating Model](02-verification-operating-model.md) defines
   how requests, criteria, evidence, decisions, and flakiness relate.
4. [Improved One-Session Plan](03-improved-one-session-plan.md) sequences the
   work into bounded, independently reviewable packages.
5. [Completion Checklist](04-completion-checklist.md) verifies this dossier.

## Scope

The session produces an evidence-backed roadmap for verification-first
workflows and lower-cost tool use. The session does not modify product source,
workflow state, GitHub configuration, stores, or MCP servers.

## Decision Boundary

Proposed implementation work begins only after a later planning decision turns
the prioritized roadmap items into tickets with acceptance criteria and
validation commands.
